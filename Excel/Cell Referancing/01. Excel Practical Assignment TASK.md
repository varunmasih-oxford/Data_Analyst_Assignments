# Explanation of Cell References

## Relative Reference

Example

```excel
=C2*D2
```

Changes automatically when copied.

Example

```
=C3*D3
=C4*D4
```

---

## Absolute Reference

Example

```excel
=E2*$M$2
```

The value in **M2** never changes while copying.

---

## Mixed Reference

Example

```excel
=P2*P$9
```

- Column changes when copied sideways.
- Row remains fixed.
